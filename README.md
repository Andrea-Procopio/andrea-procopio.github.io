# andrea-procopio.github.io

Personal website, work in progress

## Updates artwork

The Updates page uses *The Bean Eater* (c. 1584–85) by Annibale Carracci. [Source on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Carracci_-_Der_Bohnenesser.jpeg), marked public domain. The responsive WebP assets are derived from the [original image selected for the site](https://upload.wikimedia.org/wikipedia/commons/a/ae/Carracci_-_Der_Bohnenesser.jpeg) and preserve its full composition and colors.
